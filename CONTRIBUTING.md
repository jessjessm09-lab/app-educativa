# 🤝 Guía de Contribución

¡Gracias por tu interés en contribuir a la App Educativa! Toda ayuda es bienvenida.

## 🌟 Formas de Contribuir

- 🐛 Reportar bugs
- 💡 Sugerir nuevas funcionalidades
- 📝 Mejorar la documentación
- 🎨 Mejorar el diseño
- 🎮 Agregar nuevos juegos
- 🌍 Traducciones a otros idiomas

## 📋 Cómo Reportar un Bug

1. Ve a la pestaña [Issues](../../issues)
2. Haz clic en "New Issue"
3. Incluye:
   - Descripción clara del problema
   - Pasos para reproducirlo
   - Navegador y versión que usas
   - Capturas de pantalla si es posible

## 💡 Cómo Sugerir Funcionalidades

1. Abre un [Issue](../../issues)
2. Usa el título: "Feature: [Nombre de la funcionalidad]"
3. Describe:
   - Qué funcionalidad te gustaría
   - Por qué sería útil
   - Cómo te imaginas que funcionaría

## 🔧 Cómo Contribuir con Código

1. Haz un Fork del repositorio
2. Crea una rama para tu feature:
   ```bash
   git checkout -b feature/nombre-funcionalidad
   ```
3. Realiza tus cambios
4. Asegúrate de que todo funcione correctamente
5. Commit tus cambios:
   ```bash
   git commit -m "Descripción clara de los cambios"
   ```
6. Push a tu fork:
   ```bash
   git push origin feature/nombre-funcionalidad
   ```
7. Abre un Pull Request

## 📝 Estilo de Código

- Usa nombres descriptivos para variables y funciones
- Comenta las secciones complejas
- Mantén la coherencia con el estilo existente
- Usa español para comentarios y nombres de variables relacionadas con contenido educativo

## ✅ Checklist antes de un Pull Request

- [ ] El código funciona correctamente
- [ ] No hay errores en la consola
- [ ] Los cambios son compatibles con móviles
- [ ] La funcionalidad está documentada
- [ ] Has probado en diferentes navegadores

## 🎯 Ideas de Contribuciones Buscadas

- Nuevos tipos de juegos educativos
- Sistema de exportación/importación de datos
- Modo oscuro
- Estadísticas y seguimiento de progreso
- Generación automática de contenido
- Mejoras de accesibilidad

## 📧 Contacto

Si tienes preguntas sobre cómo contribuir, abre un Issue o contacta al mantenedor del proyecto.
