# 🤖 Cómo Usar la Generación con IA

## Paso 1: Obtener API Key (GRATIS)

1. Ve a: https://console.anthropic.com/
2. Haz clic en "Sign Up" (Registrarte)
3. Completa el registro (es gratis)
4. Ve a "API Keys"
5. Haz clic en "Create Key"
6. Copia la key (empieza con `sk-ant-...`)

## Paso 2: Configurar en la App

1. Abre la app en tu navegador
2. Ve a la pestaña **"Administrar"**
3. Busca la sección **"🤖 Generar Tema con IA"**
4. Pega tu API Key
5. Haz clic en "Guardar API Key"

## Paso 3: Generar Temas

1. Selecciona el curso
2. Escribe el nombre del tema
3. Describe lo que quieres generar

### Ejemplos de descripciones:

**Para Lengua:**
- "15 verbos irregulares con sus conjugaciones en presente"
- "10 figuras retóricas con ejemplos de poemas"
- "Conectores textuales clasificados por función"
- "20 palabras agudas, graves y esdrújulas"

**Para otras materias:**
- "Tabla periódica: 20 elementos con sus símbolos"
- "Países de América con sus capitales"
- "Fórmulas matemáticas básicas con ejemplos"

## ⚡ Tips para Mejores Resultados

1. **Sé específico**: "10 adjetivos calificativos con sus antónimos"
2. **Indica cantidad**: "15 ejemplos de..."
3. **Especifica categorías**: "clasificados por tipo..."
4. **Da contexto**: "para estudiantes de 2do año"

## 💰 Costos

- Anthropic da créditos GRATIS al registrarte
- Cada generación cuesta centavos
- ~50-100 temas gratis para empezar
- Después puedes pagar solo si quieres más

## 🔒 Seguridad

- Tu API Key se guarda SOLO en tu navegador
- Nadie más puede verla
- Puedes borrarla cuando quieras
- Es 100% segura

## ⚠️ Nota

La app funciona PERFECTAMENTE sin IA. La generación automática es solo una función EXTRA opcional para ahorrarte tiempo.
