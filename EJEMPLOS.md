## 💡 Consejos para Crear Temas Efectivos

1. **Equilibrio**: Incluye entre 8-16 items por tema para juegos óptimos
2. **Categorías claras**: Usa 2-4 categorías por tema
3. **Ejemplos concretos**: Mezcla definiciones con ejemplos prácticos
4. **Progresión**: Ordena de lo más simple a lo más complejo
5. **Variedad**: Combina palabras sueltas con frases cortas

## 📝 Formato Correcto

Cada línea debe tener el formato:
```
concepto|categoría
```

- Sin espacios extras antes o después del `|`
- Una línea por item
- Categorías consistentes (mismo nombre exacto)

## ❌ Errores Comunes

```
# INCORRECTO
sustantivo | Clase de palabra    # Espacios alrededor del |
verbo:Clase de palabra          # Usar : en lugar de |
adjetivo                         # Falta la categoría

# CORRECTO
sustantivo|Clase de palabra
verbo|Clase de palabra
adjetivo|Clase de palabra
```
